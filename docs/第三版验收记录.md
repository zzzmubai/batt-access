- 独立 Python 驱动临时表探针、环境清单与 Linux 检查入口；均不删除数据库。
- Qt 6 最小异步窗口和确定性假 HTTP 测试源码，已实际构建运行。
- 新环境操作教程、无凭据配置样例与实测驱动依赖锁。

环境准备中实际遇到并处理的问题：PowerShell 原始下载速度过低，改用 curl 续传后完成并核对哈希；沙箱账户生成的私有文件不能直接交给桌面账户的 VirtualBox 使用，改为桌面账户独立生成；Windows OpenSSH 拒绝 OWNER RIGHTS 权限条目，使用明确的当前用户/SYSTEM/管理员 ACL 后 SSH 成功；Qt 安装器中文路径解码失败，进入 ASCII 临时盘符方案。

Qt 的链接器和 moc 仍不能使用中文真实路径，最终在英文 SDK 目录中构建经逐文件 SHA256 校验一致的源码副本，完整命令封装在 `build-v3-qt-m0.ps1`。独立 Python 安装最初有依赖解析失败，升级独立 venv 的 pip、改用官方索引后完成安装；完整版本见 `python-resolved.txt`。MySQL 首次链接缺少 `-lz/-lssl/-lcrypto`，补齐开发包后通过，保留 [首次链接失败](test-results/v3-m0-linux/m0-export/m0-005/build.txt)。
